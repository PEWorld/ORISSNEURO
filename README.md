# kie-bot

Telegram-бот поверх KIE AI. Параметры моделей настраиваются кнопками или через `/set`.

| Команда | Модель | Что умеет |
|---|---|---|
| `/image` | GPT Image 2 | text-to-image; приложи до 16 картинок → image-to-image |
| `/kling` | Kling 2.5 Turbo Pro | text-to-video; приложи 1 картинку → image-to-video |
| `/seedance` | Seedance 2.0 | референсы (до 9 картинок + 3 видео + 3 аудио) или first/last кадры |
| `/nb2` | Nano Banana 2 | картинки, до 14 референсов |
| `/nbpro` | Nano Banana Pro | картинки, до 8 референсов |
| `/seedream` | Seedream 5.0 Pro | картинки, до 10 референсов |
| `/wan` | WAN 3.0 | видео 2–30с; референсы, первый/последний кадр, документ или ссылка |

Логика простая: выбрал модель → шлёшь текст, это промпт. Шлёшь файл — он цепляется на вход. Подпись к файлу тоже считается промптом.

## WAN 3.0 — параметры и цены (проверено 29.10.2026)

Команда `/wan`, model id `wan/3-0-video`. [Официальная схема](https://docs.kie.ai/market/wan/3-0-video), [прайс KIE](https://kie.ai/wan3.0-video).

| Параметр | Значения / назначение | По умолчанию в боте |
|---|---|---|
| `prompt` | До 20 000 символов; текст сообщения или подпись. Референсы называются Image1, Video1, Audio1 по порядку | — |
| `mode` | `ref` — референсы; `frames` — 1–2 картинки как первый/последний кадр. Локальный переключатель, в API не отправляется | ref |
| `resolution` | `480P`, `720P`, `1080P` (регистр важен) | 480P; у API 1080P |
| `aspect_ratio` | `adaptive`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16` | adaptive |
| `duration` | Целое 2–30с либо `-1` — автоматическая длина | 5 |
| `audio` | `true` / `false`, звук результата | true |
| `seed` | Целое 0–2147483647, `-` сбрасывает | случайный |
| `nsfw_checker` | `true` / `false` | false |
| `reference_link_urls` | `/set reference_link_urls https://...` — один публичный URL страницы; бот преобразует в массив API | — |
| `reference_file_urls` | `/set reference_file_urls https://...` — один URL документа или приложи документ в чат | — |

Картинки в режиме `ref` становятся `reference_image_urls` (до 10), видео — `reference_video_urls` (до 5), аудио — `reference_audio_urls` (до 5). В `frames` картинки становятся `first_frame_url` и `last_frame_url`. Другие референсы в этом режиме запрещены. Документ и ссылка на страницу несовместимы. Для сброса ссылок — `/set reference_link_urls -` и `/set reference_file_urls -`; `/clear` очищает вложения.

Картинки: JPEG/PNG/BMP/WebP, ≤20MB, стороны 240–8000px, соотношение ≤8:1. Видео: MP4/MOV, ≤100MB, стороны 240–4096px, ≤8:1. Аудио: MP3/WAV, ≤15MB (Telegram voice OGG напрямую не поддерживается). Каждый видео/аудиоклип 1–15с, суммарно ≤15с отдельно для каждого типа. Входное видео + результат ≤30с. Бот проверяет доступную длину Telegram; длительность файлов, присланных как document, размеры изображения и число страниц окончательно проверяет KIE.

Документы: DOC(X), XLS(X), PPT(X), PDF, TXT, KEY, PAGES, NUMBERS, MD — ≤100MB, многостраничные ≤50 страниц. Ссылки должны открываться без авторизации.

| Качество | Кредитов/с | USD/с | 5с | 10с | 30с |
|---|---:|---:|---:|---:|---:|
| 480P | 8 | $0.04 | 40 | 80 | 240 |
| 720P | 16 | $0.08 | 80 | 160 | 480 |
| 1080P | 32 | $0.16 | 160 | 320 | 960 |

Таблица за выход без видео на входе. С видео цена = (суммарная длина входного видео + длина результата) × ставка. Например, 5с входа + 10с результата в 720P = 240 кредитов ($1.20). При неизвестной длине входа или `duration=-1` подтверждение показывает диапазон, а остаток — по верхней границе. Фактическое списание показывается после результата. Звук не меняет опубликованную ставку. WAN Prime — отдельная модель, здесь подключён стандартный WAN 3.0.

Проверки без трат: `npm test`. `/api/health` показывает список моделей и SHA деплоя; секретов в ответе нет.

## Две роли

`ALLOWED_USER_IDS` — владельцы, всё описанное ниже. `CREATOR_USER_IDS` — креаторы, урезанная ветка.

**Ветка креатора**: только GPT Image 2, жёстко 21:9 и 1K, никаких настроек, моделей и цен. Один промпт = одна картинка (6 кредитов). Кадр появляется **прямо в сообщении «в процессе»**, одним блоком: картинка, под ней «Ваш промпт:» с промптом моноширинно, и тут же кнопка «Отправить на согласование». Кнопка не пропадает и не одноразовая — нажать можно и через несколько дней. По нажатию бот спрашивает номер кадра; ответ не модерируется. Владельцу (`OWNER_CHAT_ID`, по умолчанию первый из `ALLOWED_USER_IDS`) картинка уходит **документом**, без сжатия, вместе с промптом и текстом креатора.

`CREATOR_GENERATIONS` меняет число картинок на промпт (по умолчанию 1). Учти: Bot API не разрешает инлайн-кнопки у альбомов, поэтому при значении больше 1 картинки приходят альбомом, а кнопка — отдельным сообщением под ним.

Кадры независимы: пока считается один, можно запускать следующие. Состояние каждого лежит в хранилище отдельно, а какая из двух генераций добежала последней, решает атомарный счётчик — иначе два колбэка, пришедшие одновременно, отрисовали бы кадр дважды.

## Подтверждение перед генерацией

После промпта бот показывает окно: модель, все параметры, сколько приложено файлов, остаток кредитов, во сколько обойдётся и что останется. Задача уходит в KIE только после «✅ Генерить». `/confirm off` — отключить окно, `/confirm on` — вернуть.

Дальше появляется «⏳ Ваша генерация в процессе» с промптом моноширинным блоком, и когда результат готов, он **подменяет собой это же сообщение** — оно остаётся там, где ты его оставил, а не уезжает вниз чата.

Тонкость, из-за которой это устроено именно так: Telegram не умеет превращать текстовое сообщение в медиа, но умеет подменять медиа на медиа. Поэтому «в процессе» сразу отправляется картинкой-заглушкой ([src/placeholder.js](src/placeholder.js) собирает однотонный PNG на пару сотен байт, без зависимостей), а её `file_id` кешируется, чтобы не загружать заново. Если подменить не вышло, бот отправит результат обычным сообщением — поведение деградирует, но не ломается.

Цены лежат в [src/pricing.js](src/pricing.js), сняты с `kie.ai/pricing` 2026-08-05 (API прайс не отдаёт):

| | цена |
|---|---|
| GPT Image 2 | 6 / 10 / 16 кред. за картинку (1K / 2K / 4K) |
| Kling 2.5 Turbo Pro | 42 кред. за 5с, 84 за 10с |
| Seedance 2.0, без видео на входе | 19 / 41 / 102 / 208 кред. в секунду (480p / 720p / 1080p / 4k) |
| Seedance 2.0, с видео на входе | 11.5 / 25 / 62 / 128 кред. в секунду, но считается за (вход + выход) |

Отсюда: Seedance по умолчанию (15с, 720p) стоит **615 кредитов** — оценка показывается до запуска. Если видео на входе есть, длина входа боту неизвестна, поэтому цифра помечается как «от N». Фактическое списание видно в подписи к результату — по нему легко заметить, если таблица устарела.

## Параметры

`/settings` — кнопки со всеми полями активной модели. `/set ключ значение` — то же текстом. `/reset` — дефолты.

**GPT Image 2**: `aspect_ratio` (auto, 1:1, 3:2, 2:3, 4:3, 3:4, 5:4, 4:5, 16:9, 9:16, 2:1, 1:2, 3:1, 1:3, 21:9, 9:21), `resolution` (1K/2K/4K).

**Kling 2.5 Turbo Pro**: `duration` (5/10), `aspect_ratio` (16:9/9:16/1:1, только t2v), `sound`, `cfg_scale` (0–1), `negative_prompt` (до 500 символов).

**Seedance 2.0**: `mode` (`ref` — референсы / `frames` — первый+последний кадр; в API это взаимоисключающие режимы), `duration` (4–15), `resolution` (480p/720p/1080p/4k), `aspect_ratio` (1:1, 4:3, 3:4, 16:9, 9:16, 21:9, adaptive), `generate_audio`, `web_search`, `nsfw_checker`.

Если чего-то не хватает — есть голый API: `/model <id>` подменяет model id, `/raw {"input":{...}}` дольёт любой JSON поверх собранного ботом. `/status <taskId>`, `/credits`.

## Локальный запуск

```bash
npm install
cp .env.example .env   # вписать TELEGRAM_BOT_TOKEN, KIE_API_KEY, ALLOWED_USER_IDS
npm run dev
```

Long polling, настройки в `data/state.json`, результат ждётся опросом статуса.

> Если из России без VPN — `api.telegram.org` заблокирован, и локальный режим не стартует. Включи VPN, либо прокси (`NODE_USE_ENV_PROXY=1 HTTPS_PROXY=http://127.0.0.1:ПОРТ npm run dev`), либо просто деплой на Vercel — там этой проблемы нет.

## Деплой на Vercel

Serverless не может ждать видео пять минут в одном запросе, поэтому схема такая: вебхук Telegram только создаёт задачу, а KIE потом сам стучится на `/api/kie-callback` — всё нужное для доставки зашито в подписанной ссылке.

1. `vercel` (или импорт репозитория в дашборде).
2. Переменные окружения проекта:
   - `TELEGRAM_BOT_TOKEN`, `KIE_API_KEY`, `ALLOWED_USER_IDS`
   - `TELEGRAM_WEBHOOK_SECRET`, `CALLBACK_SECRET` — любые случайные строки
   - `PUBLIC_URL` — только если домен свой. На обычном `*.vercel.app` адрес подхватывается сам из `VERCEL_PROJECT_PRODUCTION_URL`.
3. Открыть в браузере `https://<деплой>/api/setup?token=<TELEGRAM_WEBHOOK_SECRET>` — поставит вебхук и меню команд. Делается со стороны Vercel, так что VPN не нужен. Ответ покажет, какой адрес уйдёт в KIE и какое хранилище подключено.

Если результаты не приходят — первым делом Settings → Deployment Protection: включённая защита не даст KIE достучаться до `/api/kie-callback`.

### Хранилище

Без базы настройки живут только до холодного старта. Vercel → Storage → Upstash Redis (free) → подключить к проекту: переменные подхватятся сами (`UPSTASH_REDIS_REST_*` или `KV_REST_API_*`), ничего править не надо.

### Подстраховка

`/api/cron` добирает задачи, по которым колбэк не дошёл (нужно персистентное хранилище). На Hobby-плане Vercel крон запускается раз в сутки, так что смысл в нём появляется на Pro или с внешним планировщиком. Основной путь — колбэк.
